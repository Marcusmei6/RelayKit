# Beacon Comparison

Beacon is a macOS menu-bar app with a built-in localhost bridge for Codex.

## Strengths

- Simple native Mac product.
- Clear one-click provider switching.
- Small scope.
- Built-in Responses to Chat Completions bridge.

## Limits

- Codex-specific positioning.
- Narrow gateway feature set.
- No broader model catalog/runtime hub.

## RelayKit Takeaway

Adopt the native, focused product feel. Do not limit the project to a single client or only one adapter.
