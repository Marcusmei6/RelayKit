# CC Switch Comparison

CC Switch is a Tauri 2 desktop app with React UI and a Rust backend. It manages multiple agentic tools, providers, MCP servers, skills, prompts, sessions, usage, cloud sync, and a local proxy.

## Strengths

- Broad multi-tool support.
- Rich provider presets.
- Strong local proxy features.
- Usage and session management.
- Cross-platform packaging.

## Limits

- Heavy scope.
- Not Apple-native.
- Many product surfaces compete for attention.

## RelayKit Takeaway

Borrow the idea of a stronger gateway core, but not the all-in-one control panel. RelayKit should be Mac-native and gateway-focused.
